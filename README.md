# OpenClash AI Rules

16 个主流 AI 独立分流，普通代理、规则下载、AI 默认出口、媒体和 AI 分组均自动检测与选择，无需手动优先入口。

## 自动运行

- 普通代理、媒体每 5 分钟自动测速，切换容差 150ms。
- AI 每 10 分钟检测各自网站，健康出口保持，失败自动回退。国内 AI 优先直连，失败再走节点。所有组关闭惰性检测。
- 规则下载自动检测 GitHub Raw，优先直连，失败自动使用节点。
- GitHub Actions 每天北京时间 02:17 同步；路由器每 24 小时拉取域名规则。定时任务可能延迟或因长期无活动停用，以 Actions 结果为准。
- 新订阅在覆写模块关联“添加到所有配置文件”后继承配置。通用模块不硬编码机场名或节点名。机场原有的手动总出口需指向其自动组；当前 lx.yaml 已指向故障转移。

## 使用

导入 templates/AI_Services.conf；仅启用一个优化模块，避免与旧 Bypass_Optimize.conf 重名。路由器中的本地模块结构不会自动同步 GitHub 模板，域名规则可自动更新。模块保留原订阅规则及节点，不改 LAN 网关和权限。

HTTP 网站响应检测不等于账号登录、地区解锁或生成可用；反爬可能造成误判，全部节点失败时无法保证恢复。媒体测速不保证付费内容解锁。

## 来源与维护

独立源来自 [MetaCubeX/meta-rules-dat](https://github.com/MetaCubeX/meta-rules-dat)，其许可证归上游维护者；其余使用本仓库种子及 custom/<服务>.list。来源、数量与校验值见 manifest.json。下载失败、空文件或格式异常时不覆盖旧规则。

自定义列表每行域名或 +.example.com，不写 IP、脚本或凭据。本仓库不保存机场订阅、节点密码或控制面板密钥。
